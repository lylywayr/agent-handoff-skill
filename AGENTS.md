# Project instructions (agent-neutral)

For any task in this repository, first check `docs/project-memory/INDEX.md` and the current state in `docs/project-memory/STATUS.md`; read related module history and Git commits as needed. The project Git repository is authoritative; conversation memories and the optional handoff hub are pointers, not project truth.

The only Skill entry is `SKILL.md`. Use its §15 for ordinary project work; §§2–14 and their Hub scripts apply only to projects explicitly enrolled in the GitHub Hub `main/dev` handoff mode. Do not use those scripts for arbitrary repositories.

Read-only requests must not write files. For authorized changes, validate the actual diff and tests, add a unique entry to `docs/project-memory/logs/YYYY.md`, and separately report local commit and remote-sync status. Do not commit secrets, overwrite existing work, force-push, publish or deploy without appropriate authorization. If a tool or knowledge-base backend cannot verify versioned writes, report the limitation rather than claiming success.
